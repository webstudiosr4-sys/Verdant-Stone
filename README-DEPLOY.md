# Verdant & Stone — deployment package

This is a static website package prepared for GitHub and Vercel.

## GitHub

1. Extract the ZIP archive.
2. Create a repository and upload every extracted file and the complete `assets` folder.
3. Keep the folder structure unchanged.

## Vercel

1. Import the GitHub repository into Vercel.
2. Select **Other** as the framework preset.
3. Leave the build command empty.
4. Use the repository root as the root/output directory.
5. Deploy.

The contact and project pop-up forms are portfolio demonstrations: they show a confirmation but do not transmit or store personal data.

After connecting a custom domain, update the canonical URL, Open Graph URL/image URLs, `robots.txt`, and `sitemap.xml`. Analytics and search-engine registration can then be configured with the final domain.
